# PlayFooty Club iPad app

Native Expo/React Native frontend for the PlayFooty Club platform. This app is intentionally isolated from the production Vite web frontend and uses the existing PlayFooty backend contracts.

## Stage 1

- secure PlayFooty club sign-in and session restoration
- authorised club selection
- landscape-first iPad application shell
- persistent club sidebar
- club overview dashboard design system
- honest empty states for data sources connected in later stages

## Local development

```bash
npm install
npm run typecheck
npm start
```

Open the project in Expo Go for early UI testing. A development build and TestFlight configuration will be added when native capabilities require them.
